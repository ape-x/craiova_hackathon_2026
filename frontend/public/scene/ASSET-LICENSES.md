# Scene materials

The terminal, aircraft, vehicles, vegetation, geographic illustration and airport layout are original procedural geometry. This is not surveyed Craiova geometry.

Bundled 1K diffuse surface textures are CC0 assets from Poly Haven:

- `aerial_grass_rock.jpg`: https://polyhaven.com/a/aerial_grass_rock (Rob Tuytel)
- `concrete_floor_02.jpg`: https://polyhaven.com/a/concrete_floor_02
- `asphalt_01.jpg`: https://polyhaven.com/a/asphalt_01

License: https://polyhaven.com/license — CC0, free for redistribution and commercial use.
Downloaded from the official asset API / dl.polyhaven.org on 2026-10-31. These are surface materials, not map imagery or mockup backgrounds.
Runtime loads these files locally. No external texture connection is required.
