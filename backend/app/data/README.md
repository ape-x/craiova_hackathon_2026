# Airport geography snapshot

`airports.json` is a bounded, offline subset of the public-domain
[OurAirports data](https://ourairports.com/data/), retrieved on **2026-10-31**
from its [official CSV download](https://davidmegginson.github.io/ourairports-data/airports.csv).
The data page links to the primary repository,
[davidmegginson/ourairports-data](https://github.com/davidmegginson/ourairports-data),
and places all data in the public domain. OurAirports does not guarantee its
accuracy or fitness for a particular purpose.

Source CSV SHA-256:
`6c600b7821829c2bd672c97b0c1e25b51a12e1e281fbd6fb1b698156b17d6acb`

Selection retains **4,589** large/medium airports that have an IATA code or
scheduled service, a valid three-letter IATA or four-letter ICAO code, and finite
latitude/longitude within geographic bounds. The source has 86,322 records.
Five scheduled-service records without valid IATA/ICAO identifiers are omitted.
No coordinates, airport names, or identifiers are generated by a language model.
The `icao_code` field is the source of ICAO codes; local/GPS identifiers are not
silently treated as ICAO identifiers. Each record's canonical `id`/`code` is its
IATA code if present, otherwise its ICAO code. Records sort by canonical code.

This is airport **reference geography**, not live operational data. It says
nothing about weather, opening hours, runway status, diversion suitability,
available gates, aircraft compatibility, or passenger/bus resources. The
simulation owns those properties and must distinguish them from observations.
`scheduled_service` is a snapshot attribute, not a current flight schedule.

The application reads this bundled file locally and performs no network request
for lookup or candidate matching. `airport_catalog.py` adds source name, URL and
retrieval date to returned copies. Romanian/common local city aliases translate
search terms; they do not select a preferred airport. Ambiguous city references
must be resolved by the caller, with clarification if needed.

To refresh: download the official CSV, apply the documented filter, serialize
the existing field mapping in canonical-code order, and update the snapshot
date, source digest and record count together. Review the resulting diff and run
`python -m pytest tests/test_airport_catalog.py` from `backend/`.
